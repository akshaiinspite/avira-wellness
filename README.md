# Aavira Wellness - Integrative Wellness & Inner Wellbeing

Aavira offers a dedicated space for reflection, self-awareness, and personal wellbeing. Founded by **Afeefa M. P.**, Aavira brings together counselling psychology and complementary wellness practices to support the individual as a whole.

## 🌿 Tech Stack & Architecture
- **Framework**: React 18 + TypeScript + Vite
- **Animations**: Framer Motion 3D Physics & Scroll Animations
- **Styling**: Sacred Earth Design System (Vanilla CSS with CSS Variables)
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ & npm

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
```
Static production files will be generated in the `dist/` directory, ready for hosting on Hostinger or any static server.
